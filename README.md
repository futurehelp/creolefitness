# Creole Fitness

Miami-inspired Next.js facelift for [creolefitness.com](https://creolefitness.com/).

This first iteration is a polished presentation clone: the original site’s story, classes, trainers, community mission, and testimonials are represented in a new editorial layout with Framer Motion micro-interactions. Booking and commerce are intentionally staged for a later iteration.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js App Router + TypeScript
- Framer Motion for entrance, hover, and testimonial transitions
- Tailwind CSS v4 foundation with a custom responsive design system
- Lucide icons
